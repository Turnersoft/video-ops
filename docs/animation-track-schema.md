# Turn IDE animation track schema

Tracks live beside the script: `video_ops/script/<slug>/tracks/scene-N-ide.json`.

Generated by (in priority order):

1. **LSP + knowledge export** (future) — proof trace, tactic branches, morph pipelines from `turn-lang` knowledge module
2. **`npm run sync:force`** — builds a demo track from `Show on screen:` turn blocks when no track exists

## Format

```json
{
  "version": 1,
  "sourceFile": "shared/reference/02_sets_and_equivalence_relations.turn",
  "sourceRange": { "startLine": 833, "endLine": 853 },
  "typing": {
    "charsPerSecond": 28,
    "snippet": "theorem \"example\" { ... }"
  },
  "proofPanel": {
    "exportPath": "tracks/scene-3-proof.json",
    "steps": [
      { "label": "assume h", "goal": "forall x, P x" },
      { "label": "witness g", "goal": "exists y, Q y" }
    ]
  },
  "knowledgePanel": {
    "heading": "Knowledge",
    "exportPath": "tracks/scene-2-knowledge.json"
  },
  "interactions": [
    { "atSeconds": 2.4, "kind": "click-proof-step", "stepIndex": 0 },
    { "atSeconds": 4.8, "kind": "click-branch", "branchId": "split-1" },
    { "atSeconds": 6.0, "kind": "morph", "morphId": "goal-fold-assume" }
  ]
}
```

Knowledge cards in Remotion reveal **one per completed source block**: each finished `|- … ;` where-clause, then each opened law (`disjoint {`, `cover {`), in export order.

## Lean 4 panel track

Tracks live beside the script: `video_ops/script/<slug>/tracks/scene-N-lean4.json`.

Copy the example from [`docs/examples/lean4/`](../docs/examples/lean4/) into your script’s `tracks/` folder.

### Track format

```json
{
  "version": 1,
  "sourceFile": "shared/reference/partition_equivalence.lean",
  "sourceRange": { "startLine": 7, "endLine": 14 },
  "typing": {
    "charsPerSecond": 26,
    "snippet": "example (h : Equivalence R) (a : α) : ..."
  },
  "goalPanel": {
    "exportPath": "tracks/scene-1-lean4-goal.json"
  },
  "highlights": [
    { "text": "obtain ⟨b, hb⟩", "atSeconds": 3.5 }
  ]
}
```

### Goal export format (static infoview)

Hand-author or paste from Lean’s infoview — no live LSP:

```json
{
  "version": 1,
  "title": "Goals",
  "hypotheses": [
    { "name": "h", "type": "Equivalence R" },
    { "name": "a", "type": "α" }
  ],
  "target": "∃ b, R a b",
  "steps": [
    {
      "atSeconds": 3.5,
      "label": "after obtain",
      "hypotheses": [{ "name": "hb", "type": "R a b" }],
      "target": "∃ b, R a b"
    }
  ]
}
```

`steps[].atSeconds` scrubs the goal panel over time (same idea as proof panel steps).

## Remotion layer

In `animation.json`:

```json
{
  "layers": [
    { "type": "turn-ide", "track": "tracks/scene-3-ide.json" },
    { "type": "lean4", "track": "tracks/scene-1-lean4.json" },
    {
      "type": "compare",
      "turnTrack": "tracks/scene-compare-turn.json",
      "leanTrack": "tracks/scene-compare-lean4.json"
    }
  ]
}
```

**Compare layer** — **Lean 4 on the left**, **Turn-Lang on the right** (defaults). Within each column, code is stacked above render. Use matching `captionBeats` / `atSeconds` in both tracks so highlights follow narration.

## Director vs render

- `director.say` — teleprompter lines; **editor + `showDirector` preview only**, not in exported MP4
- `layers` — what viewers see (IDE, PiP, talking-head)

## Talking-head trim

```json
{
  "type": "talking-head",
  "src": "reference/take-01.mp4",
  "trimIn": 12.5,
  "trimOut": 26.0,
  "position": "pip"
}
```

Edit trim in `/video-ops/editor` (saved back to `animation.json`).
